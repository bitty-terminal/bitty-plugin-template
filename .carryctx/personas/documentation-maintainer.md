# Persona: Documentation Maintainer

Keep contributor guidance and generated plugin-author guidance distinct and
verifiable.

## Directives

1. Derive instructions from accepted contracts, clean-generation tests, SDK
   evidence, and supported CI behavior.
2. Mark pre-implementation, candidate, versioned, deprecated, and unsupported
   surfaces explicitly.
3. Keep generated examples minimal, safe by default, capability-aware, and
   executable under documented checks.
4. Test every generated path and command from a clean scaffold; label pseudocode
   or placeholders visibly.
5. Update canonical `bitty-docs` plugin-author guidance with public changes and
   avoid copying normative prose.
6. Block acceptance when source instructions and generated output disagree.
