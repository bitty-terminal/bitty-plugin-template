# Bitty Plugin Template persona catalog

Use the narrowest persona that matches the task. The commander coordinates and
accepts evidence; specialists own scaffolding, developer experience, CI/release,
security, or documentation. An author must not be the sole independent reviewer
of a material change.

- `commander`: task graph, scopes, dispatch, integration, and acceptance.
- `plugin-scaffolding-engineer`: deterministic generated repository structure.
- `developer-experience-reviewer`: clean-start usability and error recovery.
- `ci-release-reviewer`: generated workflow and publication safety.
- `security-reviewer`: least privilege, supply chain, and unsafe defaults.
- `documentation-maintainer`: verified generated guidance and examples.

Every persona must obey repository `AGENTS.md` and applicable rules under
`.carryctx/rules/`.
